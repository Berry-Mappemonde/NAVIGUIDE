# Logos — sources et règles d'usage (relevé le 15 oct. 2026)

## NVIDIA
- `nvidia-logo-vert.svg` (vertical, format préféré), `nvidia-logo-horz.svg` (horizontal) : https://www.nvidia.com/en-us/about-nvidia/legal-info/logo-brand-usage/ (fichiers `/content/dam/en-zz/Solutions/about-nvidia/logo-and-brand/`).
- `nvidia-logo-vert-blk.png`, `nvidia-logo-vert-wht.png` (taille « mid ») : NVIDIA Newsroom, https://nvidianews.nvidia.com/multimedia/corporate/nvidia-logos
- Règles : https://international.download.nvidia.com/partnerforce-us/Brand-Guidelines/NVIDIA_LogoGuidelines.pdf
  - Logo utilisable seulement avec l'accord écrit de NVIDIA. Usages approuvés cités : co-branding, sponsor, « logo garden », applications éducatives ou de recherche qui utilisent des technologies NVIDIA.
  - Logo bicolore sur fond clair ; mot en blanc sur fond sombre. Pas de déformation, pas de recoloration, pas d'effet, pas d'œil séparé du mot. Marge minimale = hauteur du « n ». Taille minimale 38 px (vertical) / 15 px (horizontal). Un seul logo NVIDIA par vue.
  - Toujours écrire « NVIDIA » en majuscules.

## Nebius
- `nebius/SVGs|PNGs|PDFs/NEBIUS-color` et les versions contour noir / blanc / bleu profond : kit officiel (zip « NEBIUS-logos(07.25) ») de https://nebius.com/media-kit
- `nebius-logo-site.svg` : https://nebius.com/logo.svg
- Règles : https://nebius.com/brand-assets/trademark-usage-guidelines — usage exact sans modification (forme, couleur, proportions) ; liens vers les sites officiels ; accord écrit sauf exceptions ; en cas de doute : trademarkusage@nebius.com.

## Nebius Token Factory
- `tokenfactory-logo-Light.svg` / `tokenfactory-logo-Dark.svg` : logo « Main-logo-TF » de la documentation officielle (https://docs.tokenfactory.nebius.com, en-tête). Je n'ai pas trouvé de kit presse dédié ; la marque relève des règles Nebius ci-dessus.
- `tokenfactory-favicon.svg` : favicon de https://tokenfactory.nebius.com (repère carré, à n'utiliser qu'en petite taille).

## Pour la vidéo / la galerie Devpost
Les règles du hackathon ne permettent pas de logos tiers autres que les nôtres sans accord (doc § 0 : « pas de logos tiers hors les nôtres »). Préférer écrire en texte « NVIDIA Nemotron on Nebius Token Factory » ; si les logos sont utilisés, les placer comme mention technologique (« Built with »), sans suggérer de partenariat ni de parrainage.
